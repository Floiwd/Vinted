# Vinted Assistant AI (Version Sans Installation)

Cette application a été convertie pour fonctionner **sans NPM, sans Node.js et sans installation**.

## Comment l'utiliser ?

1. **Ouvrez simplement le fichier `index.html`** dans votre navigateur (Double-cliquez dessus).
2. Au premier lancement, l'application vous demandera votre **Clé API Google Gemini**.
   - Vous pouvez en obtenir une gratuitement ici : [Google AI Studio](https://aistudio.google.com/app/apikey)
3. Prenez une photo d'un vêtement et l'assistant générera :
   - Un titre optimisé.
   - Une description complète.
   - Une estimation de prix.

## Hébergement

Vous pouvez héberger ce fichier `index.html` n'importe où :
- Netlify Drop (glissez simplement le dossier).
- GitHub Pages.
- Sur votre téléphone.

Tout le code est contenu dans `index.html`.
